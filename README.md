# My Portfolio Website

A professional portfolio website showcasing the work of Adan Shah, Full Stack Developer.

## Features

- **Responsive Design**: Mobile-first approach with Bootstrap 5.3.3
- **Modern UI**: Dark theme with Material UI components
- **Portfolio Showcase**: Filterable project gallery with detailed views
- **Performance Optimized**: Lazy loading, deferred scripts, and efficient resource management
- **SEO Friendly**: Proper meta tags, semantic HTML, and alt attributes

## Technologies

- HTML5
- CSS3 / Bootstrap 5.3.3
- JavaScript / ES6+
- AOS (Animate On Scroll)
- Swiper.js (Carousels)
- GLightbox (Image Gallery)
- Isotope.js (Filtering)

## Performance Optimizations

✅ **Lazy Loading**: All images use `loading="lazy"` attribute except for above-the-fold content  
✅ **Deferred Scripts**: Non-critical scripts load with `defer` attribute  
✅ **SEO Optimization**: Comprehensive meta tags and alt attributes  
✅ **Clean Code**: Removed unused/commented code  
✅ **Proper Semantic HTML**: Improved accessibility and SEO
